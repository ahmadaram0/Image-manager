# Java-Image-Manager
A CLI and GUI based Java Image Manager Implemented with OOP principles showcasing my talent in code reusability across part 1 and 2 with detailed comments simplifying every process. This project was done within 2 weeks and there's still room for improvement so that It may automatically index images in a directory and scrape it's metadata.

# How to simply run the program 

1. Navigate to the page for the latest release shown under the releases section of this Github Repository

2. Download the jar files for the programs you wish to execute

3. Ensure that your system has JRE 21 installed in order to run either program

4. open up your desktop's terminal app and navigate to the directory containing the jar file.
   this can be done using the cd command followed by the directory.
   For Example:
   ```bash
   cd Users/Ahmad/Downloads
   ```

6. Run the java command with the -jar flag followed by the name of the file you wish to execute.
   For example:
   ```bash
    java -jar image-manager-gui-1.0.jar
   ```

8. Play around with it and have fun. You can also try adding an image with the file name ```Nul.png```
   

# How to setup both parts in order to run and debug the code

1. Get your IDE of choice that's capable of running Java (preferably Eclipse).

2. Press the green button labelled with "Code" on this Github Project and Download the files as a ZIP

3. Unzip the directory and Import the folder into your IDE of choice.

4. Select the part 2 folder within your IDE of choice and Build a path to the External Jar file called Console.jar

5. The setup is now complete and you should now be able to run Images.java in the part 1 directory for a CLI Experience
   or ConsoleMediaImages.java in the part 2 directory for an enhanced GUI experience
